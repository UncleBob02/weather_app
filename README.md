# Weather App

A Flutter weather app that shows current conditions for any location you search. My first solo mobile app project.

## Features

- Search for weather conditions by city
- View temperature, "feels like" temperature, and general conditions
- See humidity and wind speed at a glance
- Clean, simple interface built with Flutter's Material widgets

## Getting Started

### Prerequisites

- [Flutter SDK](https://docs.flutter.dev/get-started/install) (stable channel)
- A connected device, emulator, or simulator

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/your-username/weather_app.git
   cd weather_app
   ```
2. Install dependencies
   ```bash
   flutter pub get
   ```
3. Run the app
   ```bash
   flutter run
   ```
